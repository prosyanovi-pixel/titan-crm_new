# Компоненты фронтенда TITAN CRM

## Обзор
Эта документация описывает архитектуру и компоненты фронтенд части системы TITAN CRM.

## Структура компонентов

### Атомные компоненты
- Button - Базовые кнопки
- Input - Поле ввода данных
- Modal - Модальные окна
- Table - Таблицы данных
- Form - Формы ввода
- Card - Карточки информации

### Молекулы
- UserCard - Карточка пользователя
- ProjectCard - Карточка проекта
- DocumentCard - Карточка документа
- NotificationItem - Элемент уведомления

### Макеты
- Header - Заголовок приложения
- Sidebar - Боковая панель
- DashboardLayout - Макет панели управления
- FormLayout - Макет форм

### Организмы
- UserList - Список пользователей
- ProjectList - Список проектов
- DocumentList - Список документов
- LegalCaseList - Список юридических дел

## Паттерны использования

### Компоненты с состоянием
- Использование React Hooks для управления состоянием
- Реализация контекста для глобальных данных
- Обработка форм с помощью React Hook Form

### Доступность
- Поддержка клавиатурной навигации
- АRIA метаданные
- Семантическая разметка HTML

## Технические спецификации

### Структура компонентов
Каждый компонент должен содержать:
- Основной файл компонента (.tsx)
- Файл стилей (.css или Tailwind)
- Тесты (если применимо)
- Документацию
