## Как использовать документацию
1. Начните с [API Documentation](api/API.md) для понимания интерфейсов
2. Ознакомьтесь со [схемой базы данных](database/README.md) для понимания структуры данных
3. Изучите [компоненты фронтенда](components/README.md) для разработки интерфейса
4. Просмотрите документацию по модулям для детального понимания функциональности
