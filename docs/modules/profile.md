# Модуль Профиль (profile)

## Назначение
Личный кабинет пользователя: просмотр и изменение собственных данных, настройка интерфейса.

## Основные функции
- Просмотр и редактирование личных данных (имя, контакты)
- Смена пароля
- Персональные настройки пользователя (user settings)

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/profile/pages/Profile.tsx`, `api/profileService.ts`
- Backend: `backend/modules/profile/routes.js`

### API конечные точки
- `GET/PUT /api/profile` — данные текущего пользователя
- `POST /api/profile/change-password` — смена пароля
- `GET/PUT /api/profile/settings` — персональные настройки

### Схема базы данных
- `users` (личные данные)
- `user_settings` (настройки пользователя)

## Структура компонентов
- Profile.tsx (личный кабинет)

## Лучшие практики
- Доступ только к данным текущего пользователя (id из JWT), не запрашивать чужие профили
- Смена пароля — с проверкой текущего пароля и минимальной длиной
