# Модуль Юристы (lawyers)

## Назначение
Управление юридическим персоналом, специализациями, судами и судьями; привязка юристов к делам.

## Основные функции
- Реестр юристов и их специализаций
- Справочники судов и судей
- Статусы юристов
- Связка юристов с юридическими делами (назначение на дела)

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/lawyers/pages/LawyersPage.tsx`, `api/lawyerService.ts`, `api/lawyers.api.ts`, `api/endpoints.ts`
- Backend: `backend/modules/lawyers/routes.js`

### API конечные точки
- `GET/POST /api/lawyers` — список/создание юристов
- `GET/PUT/DELETE /api/lawyers/:id` — карточка юриста
- Справочники судов — отдельный эндпоинт `/api/courts` (реализация в `backend/modules/legal_cases/controllers/courts`), исходы дел — `/api/case-outcomes`

### Схема базы данных
- `lawyer_status` — статусы юристов (справочник)
- `specialization` — специализации
- `judges`, `courts` — суды и судьи
- Связь с делами — через `legal_cases` и таблицы связей дел

## Структура компонентов
- LawyersPage.tsx (реестр юристов)

## Лучшие практики
- Статусы и справочники держать в отдельных таблицах-справочниках, не захардкоживать в коде
- Права на работу с юристами контролировать через централизованную систему прав
