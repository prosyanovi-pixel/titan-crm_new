# Модуль Дашборд (dashboard)

## Назначение
Главный экран системы: сводные показатели, ключевые метрики бизнеса и быстрые действия.

## Основные функции
- Сводка по ключевым доменам: контрагенты, дела, проекты, финансы, почта
- Виджеты с агрегированными показателями
- Быстрые переходы и действия
- Данные для отчётов дашборда формируются на бэкенде

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/dashboard/pages/Dashboard.tsx`
- Backend: `backend/modules/dashboard/routes.js`

### API конечные точки
- `GET /api/dashboard/stats` — агрегированные данные для виджетов (см. `backend/modules/dashboard/routes.js`)

### Схема базы данных
- Отдельных таблиц не создаёт — агрегирует данные остальных модулей

## Структура компонентов
- Dashboard.tsx (страница)

## Лучшие практики
- Тяжёлые агрегации выполнять на бэкенде, не нагружая браузер
- Кэшировать ответы дашборда (TanStack Query) и обновлять по событиям
