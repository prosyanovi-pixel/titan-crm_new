# Модуль Воркфлоу (workflow)

## Назначение
Бизнес-процессы и воркфлоу: рабочие потоки, этапы, условия переходов и интеграция с сущностями CRM.

## Основные функции
- Определение рабочих потоков (workflows) и их этапов
- Условия и переходы между этапами
- Привязка воркфлоу к сущностям (договоры, задачи, сделки)

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/workflow/pages/WorkflowPage.tsx` (при наличии)
- Backend: `backend/modules/workflow/routes.js`

### API конечные точки
- `GET/POST /api/workflow/...` — воркфлоу и этапы (см. `backend/modules/workflow/routes.js`)

### Схема базы данных
- `workflows` — рабочие потоки
- `workflow_stages` — этапы воркфлоу
- Таблицы условий/переходов (см. миграции модуля)

## Структура компонентов
- WorkflowPage.tsx (конструктор воркфлоу)

## Лучшие практики
- Движение по воркфлоу логировать в активности сущности
- Переходы валидировать на бэкенде (права, условия этапа)
