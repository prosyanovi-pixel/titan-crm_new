# Модуль Ошибки (errors)

## Назначение
Служебный модуль страниц ошибок приложения (например, страница 404).

## Основные функции
- Отображение страницы «не найдено» (NotFound)
- Точка входа для обработки ошибочных маршрутов фронтенда

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/errors/pages/NotFound.tsx`

### API конечные точки
- Отсутствуют (модуль только UI)

## Схема базы данных
- Не требуется

## Структура компонентов
- NotFound.tsx

## Лучшие практики
- Не размещать бизнес-логику в этом модуле — только представление ошибок
