# Модуль Календарь

## Назначение
Модуль календаря обеспечивает планирование событий, встреч и задач с отображением в календарной сетке, а также напоминания.

## Основные функции
- Создание, редактирование и удаление событий
- Привязка событий к делам, проектам и другим сущностям
- Статусы событий и типы событий
- Напоминания о предстоящих событиях

## Технические спецификации

### Ключевые файлы
- Frontend: `frontend/src/modules/calendar/pages/` (Calendar, CalendarPage), `api/calendarService.ts`, `api/endpoints.ts`
- Backend: `backend/modules/calendar/routes.js`

### API конечные точки
- `GET/POST /api/calendar/events` — список/создание событий
- `GET/PUT/DELETE /api/calendar/events/:id` — работа с конкретным событием
- Напоминания: отправляются через уведомления при наступлении времени события

### Схема базы данных
- `calendar_events` — события календаря
- `calendar_status` — статусы событий (справочник)
- `event_type` — типы событий (справочник)
- `calendar_event_notifications` — настройки/факты напоминаний

## Структура компонентов
- Calendar.tsx (календарная сетка)
- CalendarPage.tsx (страница модуля)
