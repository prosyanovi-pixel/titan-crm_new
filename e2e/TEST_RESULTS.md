### Запуск тестов

```bash
# Все тесты

# В режиме UI
npm run test:e2e:ui

# В режиме отладки
npm run test:e2e:debug

# Только Chromium
npx playwright test --project=chromium

# Просмотр отчёта
npm run test:e2e:report
```
