# Создание независимого модуля «Продажи» (Sales CRM Hub)

Вы выбрали Вариант Б: создание полноценного отдельного хаба (модуля) для продаж. 
Этот модуль не заменит «Проекты», а будет решать специфическую задачу — визуализацию и управление циклом продаж (воронкой) от первого контакта до успешного закрытия и оплаты.

## ⚠️ Требуется подтверждение

Ознакомьтесь с планом ниже. Если вы согласны с подходом, нажмите **Proceed**, и я приступлю к реализации.

## Принятые решения

На основе ваших ответов мы зафиксировали следующие решения:

- **Воронка (Статусы):** Будет создан отдельный справочник этапов воронки продаж (например: Входящий лид -> Переговоры -> Подготовка КП -> Согласование Договора -> Успешно/Отказ).
- **Воркфлоу продаж:** Мы разработаем механизм и типовые воркфлоу для автоматизации этапов (постановка задач, смена ответственных) при движении сделки по воронке.
- **Интеграция с бекендом:** Будет добавлена агрегация данных (КП, договоры, маржа) в `projectService.js`.
- **Мастер создания сделки (Wizard):** Будет реализован предложенный процесс из 3 шагов (Лид/Компания -> Первичное КП -> Задачи).
