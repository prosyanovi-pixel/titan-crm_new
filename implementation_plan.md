# Создание независимого модуля «Продажи» (Sales CRM Hub)

Вы выбрали Вариант Б: создание полноценного отдельного хаба (модуля) для продаж. 
Этот модуль не заменит «Проекты», а будет решать специфическую задачу — визуализацию и управление циклом продаж (воронкой) от первого контакта до успешного закрытия и оплаты.

По умолчанию я буду использовать стандартные статусы, если вы не укажете иное. да и возможность отслеживания далее в модуле продажи. и воркфлов добавитьи разработать типовые воркфлов для продаж
- **Интеграция с бекендом:** Для отображения индикаторов (количество КП, договоров, маржа) прямо на карточках сделок на доске, мне потребуется добавить агрегацию в API проектов. Согласны ли вы на небольшие доработки бекенда (в `projectService.js`)?   
- **Мастер создания сделки (Wizard):** Вы запросили мастера для распределения данных по модулям при создании сделки. Какие именно шаги вы хотите видеть в этом мастере? Предлагаемый вариант:
  1. **Лид и Компания** (Создание/выбор контрагента и заполнение базовой информации о сделке)
  2. **Первичное КП** (Опциональное создание черновика коммерческого предложения)
  3. **Задачи** (Постановка первого звонка/встречи)
  Вы согласны с таким набором шагов, или нужно добавить что-то ещё (например, загрузку файлов)?
