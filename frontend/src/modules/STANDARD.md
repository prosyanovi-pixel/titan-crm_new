# Стандарт Фронтенд-Модуля Titan CRM

Данный документ описывает обязательную структуру и правила разработки для фронтенд-модулей в проекте Titan CRM.

## Структура папки модуля
Каждый модуль должен находиться в `frontend/src/modules/[module_name]` и иметь следующую структуру:

- `api/` — Методы взаимодействия с Backend API.
- `components/` — Специфичные для модуля UI-компоненты.
- `hooks/` — Кастомные хуки модуля (например, для управления состоянием таблиц).
- `pages/` — Основные страницы (экраны) модуля.
- `types/` — TypeScript интерфейсы и типы.
- `index.ts` — Точка входа, экспортирующая основные компоненты и роуты.

## Правила именования
- Компоненты: `PascalCase` (например, `ProjectTable.tsx`).
- Функции и хуки: `camelCase` (например, `useProjectData.ts`).
- Стили: Использовать Tailwind CSS и компоненты из `@/components/ui`.

## Интеграция с API
- Все запросы должны использовать общую обертку `api` из `@/lib/api`.
- Пути запросов не должны содержать `/api/`, так как префикс добавляется автоматически.
- Обязательно использование TypeScript для типизации ответов.

## Локализация
- Добавление новых строк осуществляется в `frontend/src/lib/i18n/locales/ru.json`.
- Использование хука `useTranslation` обязательно.

## Стандарты UI
1. **Таблицы**: Использовать `DataTable` или `SortableTableHead` для поддержки изменения размера колонок.
2. **Диалоги**: Использовать компоненты `Dialog` из Radix UI (через `/ui/dialog`).
3. **Иконки**: Использовать `lucide-react`.

---
*Примечание: Все комментарии в коде должны быть на русском языке.*
