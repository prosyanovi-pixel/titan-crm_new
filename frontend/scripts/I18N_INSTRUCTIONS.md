
# Автоматизация перевода (i18n Scanner)

В этом проекте используется скрипт для автоматического поиска жестко закодированных русских строк и замены их на ключи интернационализации.

## Как использовать

### 1. Запуск сканера
Выполните команду в терминале:
```bash
npm run scan:i18n
```

### 2. Что делает скрипт
*   Сканирует папку `src` на наличие `.tsx` файлов.
*   Ищет кириллицу внутри JSX-тегов (например, `<div>Текст</div>`).
*   Ищет кириллицу в популярных атрибутах (`placeholder`, `title`, `label`, `description`, `subtitle`, `breadcrumb` и др.).
*   Ищет кириллицу в вызовах функций уведомлений (`toast.success('Текст')`, `confirm('Текст')`).
*   Генерирует читаемый ключ на основе транслитерации (например, `Новая задача` -> `generated.novaya_zadacha`).
*   Заменяет текст в коде на вызов функции перевода: `{t('generated.novaya_zadacha')}`.
*   Автоматически добавляет импорт `import { useTranslation } from '@/lib/i18n';`, если его нет.
*   Сохраняет все новые найденные пары "ключ-значение" в файл `missing_locales.json` в корне проекта.

### 3. Ручные действия (ОБЯЗАТЕЛЬНО)
Скрипт использует регулярные выражения и не является полноценным AST-парсером, поэтому требует небольшой ручной доработки после запуска:

**А. Перенос переводов**
1. Откройте созданный файл `missing_locales.json`.
2. Скопируйте его содержимое.
3. Вставьте новые ключи в объект `general` в файле `src/lib/i18n/locales/ru/general.ts` (или распределите по другим файлам локализации).
4. После переноса файл `missing_locales.json` можно удалить.

**Б. Инициализация хука**
Скрипт добавляет `import`, но **не может** гарантированно вставить `const { t } = useTranslation();` в правильное место внутри вашего компонента.

1. Проверьте измененные файлы (используйте `git diff` или вкладку Source Control в IDE).
2. Если компонент теперь использует `t('...')`, но не имеет инициализации хука, добавьте её вручную:

```tsx
export function MyComponent() {
  const { t } = useTranslation(); // <--- Добавить эту строку в начале компонента
  
  return <div>{t('generated.my_key')}</div>;
}
```

## Настройка

Вы можете изменить поведение скрипта, отредактировав файл `scripts/scan-i18n.js`:

*   **`TARGET_ATTRIBUTES`**: Массив атрибутов HTML/React, в которых нужно искать текст (например, добавить `tooltip`).
*   **`TARGET_FUNCTIONS`**: Массив имен функций, аргументы которых подлежат переводу.
