# Инструкция по установке результатов дел (case outcomes)

## 1. Выполните миграцию базы данных

```bash
cd backend

# Вариант 1: Через psql напрямую
psql -h localhost -U postgres -d titan_crm -f migrations/63_create_case_outcome_table.sql

# Вариант 2: Через node
node -e "
const fs = require('fs');
const db = require('./db');
const sql = fs.readFileSync('migrations/63_create_case_outcome_table.sql', 'utf8');
db.query(sql).then(() => {
  console.log('✅ Migration 63 completed successfully');
  process.exit(0);
}).catch(err => {
  console.error('❌ Migration failed:', err.message);
  process.exit(1);
});
"
```

## 2. Перезапустите backend сервер

```bash
cd backend
npm run dev
```

## 3. Проверьте работу

1. Откройте **Настройки** → **Модули** → **Юристы**
2. Перейдите на вкладку **«Результаты дел»**
3. Вы увидите три результата по умолчанию:
   - **Выиграно** (зелёный)
   - **Выиграно частично** (жёлтый)
   - **Проиграно** (красный)

## 4. Использование

Теперь вы можете:
- **Добавлять** новые результаты дел через кнопку «+ Добавить»
- **Редактировать** существующие (название, цвет, описание)
- **Удалять** ненужные результаты
- **Менять цвет** каждого результата через ColorPicker

## 5. Применение в делах

В модуле **Юристы** → **Судебные дела**:
- В таблице дел появилась колонка «Результат» (можно включить в настройках таблицы)
- При редактировании дела в поле «Исход дела» теперь отображаются все настроенные результаты
- Цвет результата автоматически подставляется из базы данных
