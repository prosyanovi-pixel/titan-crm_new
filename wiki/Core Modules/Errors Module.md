# Errors Module

> 📄 **Синхронизировано** с [docs/modules/errors.md](../../docs/modules/errors.md) — актуальная компактная спецификация модуля.

## Назначение (Purpose)
Служебный модуль страниц ошибок приложения (например, страница 404 Not Found).

## Основные функции (Core Functions)
- Отображение страницы «не найдено» (NotFound)
- Точка входа для обработки ошибочных маршрутов фронтенда

## Технические спецификации (Technical Specifications)

### Ключевые файлы (Key Files)
- Frontend: `frontend/src/modules/errors/pages/NotFound.tsx`

### API конечные точки (API Endpoints)
- Отсутствуют (модуль только UI). Ошибки бэкенда обрабатываются общим middleware.

### Схема базы данных (Database Schema)
- Не требуется

## Структура компонентов (Component Structure)
- NotFound.tsx

## Лучшие практики (Best Practices)
- Не размещать бизнес-логику в этом модуле — только представление ошибок
- Не дублировать 404-логику: использовать единый компонент через маршрутизатор
