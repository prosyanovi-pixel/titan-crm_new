# Конфигурация TITAN CRM

Эта директория содержит конфигурационные файлы для различных инструментов.

## Файлы конфигурации

- `jest.config.ts` - Конфигурация Jest для root-level тестов
- `playwright.config.ts` - Конфигурация Playwright для E2E тестов
- `codecov.yml` - Конфигурация Codecov для отчетов о покрытии
- `setupTests.ts` - Настройка тестового окружения для Jest

## Важные замечания

При изменении путей в конфигурационных файлах, убедитесь что все пути указывают на правильные расположения после реорганизации проекта.
